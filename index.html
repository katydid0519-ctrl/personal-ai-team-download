v0.8.7

팀장석과 업무 화면 정리

팀장석의 책상·모니터·직원 배치를 다듬었습니다. 직원 모니터에서 작업·승인·완료 상태를 확인하고 관련 업무를 열 수 있습니다.

v0.8.7

배치를 미리 보고 수정

가구를 놓기 전에 위치와 통행 가능 여부를 확인하고, 오류를 누르면 문제 위치로 이동합니다. 책상 재배정과 미저장 변경 안내도 지원합니다.

v0.8.7

더 자연스러운 직원 표현

헤어·눈·표정을 확대해 비교하고 여러 방향의 외형을 함께 볼 수 있습니다. 옆모습 입 모양과 이동 장면, 축소 화면의 이름 가독성을 개선했습니다.

v0.8.5부터

AI 연결을 설정에서 확인

설정 → AI 연결에서 Codex 상태, 계정, 사용 가능한 모델을 확인하고 ChatGPT로 로그인할 수 있습니다. 자동 탐색에 실패하면 Codex 실행 파일을 직접 선택하세요.

v0.8.6

더 선명해진 픽셀 사무실

오크 & 잉크 블루, 클린 스튜디오, 월넛 라운지 색상을 고르고 가구 마감도 조정할 수 있습니다. 팀장석·회의 공간·카페의 푯말은 직접 옮길 수 있습니다.

v0.8.6

빠른 배치 편집

꾸미기 화면에서 가구 복사·붙여넣기는 Ctrl+C·Ctrl+V, 되돌리기는 Ctrl+Z, 다시 실행은 Ctrl+Y, 삭제는 Del을 사용합니다. 구역 밖 가구는 한 번의 경고와 테두리로 알려줍니다.

QUICK START

처음 시작하기

  1. 1
    운영체제에 맞는 파일을 실행합니다.

    Windows는 설치형 또는 포터블, Apple Silicon Mac은 DMG 또는 ZIP, x64 Linux는 AppImage 또는 DEB를 선택하세요.

  2. 2
    안내 창에서 샘플 팀으로 시작합니다.

    샘플 팀 적용으로 기본 담당 업무와 작동 규칙을 넣고, 팀장 지시 예시를 복사해 첫 요청을 바로 연습할 수 있습니다.

  3. 3
    AI 연결을 확인합니다.

    설정 → AI 연결에서 Codex 연결을 확인하고 ChatGPT로 로그인하세요. 연결을 마친 뒤 직원을 선택해 첫 작업을 요청합니다.

BEFORE YOU INSTALL

알아두면 좋은 점

  • AI 업무 실행에는 Codex 설치와 사용자 ChatGPT 로그인이 필요합니다.
  • 직원 설정·외형·대화와 작업 자료는 각 PC에 저장되며, 앱 업데이트 후에도 이어서 사용합니다.
  • 다운로드 전 파일이 맞는지 확인하려면 릴리스 페이지의 SHA256SUMS-0.8.7.txt를 사용하세요.
  • 소스 코드 저장소는 비공개로 관리되며, 이 페이지와 릴리스는 설치 파일 배포 전용입니다.
