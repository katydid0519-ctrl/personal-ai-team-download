QUICK START

처음 시작하기

  1. 1
    운영체제에 맞는 파일을 실행합니다.

    Windows는 설치형 또는 포터블, Apple Silicon Mac은 DMG 또는 ZIP, x64 Linux는 AppImage 또는 DEB를 선택하세요.

  2. 2
    안내 창에서 샘플 팀으로 시작합니다.

    샘플 팀 적용으로 기본 담당 업무와 작동 규칙을 넣고, 팀장 지시 예시를 복사해 첫 요청을 바로 연습할 수 있습니다.

  3. 3
    AI 연결을 확인합니다.

    설정 → AI 연결에서 Codex 연결을 확인하고 ChatGPT로 로그인하세요. 연결을 마친 뒤 직원을 선택해 첫 작업을 요청합니다.

TEAM PROFILES

공개 직원 프로필

현재 팀에서 사용하는 직원별 역할·모델·작동 규칙입니다. 아래 ZIP으로 팀을 한 번에 가져오거나, 직원별 규칙을 복사해 필요한 부분만 사용할 수 있습니다.

직원 설정 한 번에 가져오기

공개된 직원 15명의 이름, 담당 업무, 모델과 작동 규칙이 들어 있습니다.

  1. 설정 ZIP을 내려받아 압축을 풀지 않고 보관합니다.
  2. 앱에서 설정 → 팀 설정 옮기기 → 설정 가져오기를 선택합니다.
  3. ZIP을 열고 직원 목록을 확인한 뒤 백업 후 가져오기를 누릅니다.

현재 직원과 외형은 가져온 팀과 기본 외형으로 바뀌며, 기존 팀 설정은 적용 전에 백업됩니다. 대화·작업 기록과 로그인 정보는 유지됩니다. 스킬 라이브러리는 파일에 포함되지 않습니다. 가져온 모델이 계정에서 지원되는지도 확인해 주세요.

직원 한 명의 규칙만 쓰려면 아래에서 규칙만 복사를 누르세요. 앱에서 직원 → 해당 직원의 설정 → 모델·규칙 → 작동 규칙에 붙여 넣고 변경 저장을 누르면 됩니다.

BEFORE YOU INSTALL

알아두면 좋은 점

  • AI 업무 실행에는 Codex 설치와 사용자 ChatGPT 로그인이 필요합니다.
  • 직원 설정·외형·대화와 작업 자료는 각 PC에 저장되며, 앱 업데이트 후에도 이어서 사용합니다.
  • 다운로드 전 파일이 맞는지 확인하려면 릴리스 페이지의 SHA256SUMS-0.8.8.txt를 사용하세요.
  • 소스 코드 저장소는 비공개로 관리되며, 이 페이지와 릴리스는 설치 파일 배포 전용입니다.
