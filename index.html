QUICK START

처음 시작하기

  1. 1
    파일을 내려받아 실행합니다.

    설치형은 설치를 마친 뒤, 포터블은 내려받은 EXE를 바로 실행하세요.

  2. 2
    안내 창에서 샘플 팀으로 시작합니다.

    샘플 팀 적용으로 기본 담당 업무와 작동 규칙을 넣고, 팀장 지시 예시를 복사해 첫 요청을 바로 연습할 수 있습니다.

  3. 3
    Codex 또는 ChatGPT로 로그인합니다.

    직원을 선택해 역할과 작업 요청을 설정한 뒤 팀을 운영하세요.

BEFORE YOU INSTALL

알아두면 좋은 점

  • 앱의 AI 연동에는 사용자의 Codex 또는 ChatGPT 로그인 환경이 필요합니다.
  • 사용자가 만든 직원 설정과 외형 데이터는 각 PC에 따로 저장됩니다.
  • 다운로드 전 파일이 맞는지 확인하려면 릴리스 페이지의 SHA256SUMS-0.8.4.txt를 사용하세요.
  • 소스 코드 저장소는 비공개로 관리되며, 이 페이지와 릴리스는 설치 파일 배포 전용입니다.
